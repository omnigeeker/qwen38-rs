**⚠️ 重要限定（必须并列说明，否则会过度解读）**：
1. FlagRelease 的寒武纪条目 README 明确写道：**"Requested by Cambricon, the file of docker image and model files should be applied by email"**（镜像与模型文件需发邮件至 ecosystem@cambricon.com 申请），而其他厂商条目多为开放下载。**因此"条目少"部分是寒武纪自身的发布策略（商业门槛）所致，不能100%等同于"能力缺失"。**

3. 因此正确表述是：**在唯一一个可跨芯片横向对比的公开第三方模型仓库中，寒武纪的覆盖度显著低于几乎所有国产同行，且完全缺席 2026 年全部新一代旗舰模型。** 这是一个可程序化复核的**相对**指标，不是绝对能力判决。
